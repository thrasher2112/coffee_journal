Coffee Journal Handoff Summary
------------------------------

Current Repository State
- Root-level `docker-compose.yml` now orchestrates `db` (Postgres 16), `api` (FastAPI + Alembic seed runner), and `web` (React/Vite/Tailwind PWA). `docker compose up --build` from repo root boots the full stack (API :8000, frontend :3000).
- Backend (`coffee_journal/src/coffee_journal`) contains SQLAlchemy models for Beans & Brews, Pydantic schemas, CRUD modules, routers for beans/brews/metrics/import-export, Alembic migrations, and a seed script adding 3 beans + 2 brews. Health + `/api/*` endpoints documented in OpenAPI.
- Tests: `tests/test_health.py`, `tests/test_beans.py`, `tests/test_brews.py` run via `python -m pytest` (SQLite in-memory). Ruff enforced via `pyproject.toml`.
- Frontend lives in `frontend/` (React + Vite + Tailwind). It implements the Quick Log, Beans admin, Best Cups dashboard, Settings (offline vault, import/export, sync stub), style guide (`src/assets/style-guide.md`), and PWA assets (manifest + SW). Styling references `codex/coffee_journal/style_example.jpg` with dark café aesthetic.
- Documentation: `PROTOTYPE.md` updated with runbook + curl examples; `coffee_journal/README.md` lists Docker/PWA flow; `HANDOFF.txt` (this doc) summarizes status.

Infrastructure & Commands
- `.env.example` (copy to `.env`) defines DB creds plus `API_URL`/`FRONTEND_URL`/`VITE_API_URL`. Compose + Makefiles read it automatically.
- Make targets (repo root `Makefile`): `docker-up`, `docker-down`, `migrate`, `seed`, `frontend-build`, `api-test`. API-specific commands also live in `coffee_journal/Makefile`.
- Backend container entrypoint runs `alembic upgrade head` + `python -m coffee_journal.scripts.seed_db` before uvicorn. Frontend container builds static assets then serves via `serve -s dist -l 3000`.

- Harden import/export (validation + pagination) and add multi-tenant guard rails if cafes share a deployment.

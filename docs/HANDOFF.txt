Coffee Journal — Current State (2026-03-26)
--------------------------------------------

Stack
- Backend: FastAPI + SQLAlchemy 2.0 + Alembic + PostgreSQL (psycopg3), Python 3.11
- Frontend: React 18 + TypeScript + Vite + Tailwind, PWA
- Auth: Magic link (passwordless) → JWT HttpOnly cookie, 24h lifetime
- Tests: 70 backend (pytest/SQLite), 17 frontend (vitest/RTL)
- CI: GitHub Actions (lint + test + build on PR)

What's Implemented
- Full passwordless auth: magic-link email → JWT session → session revocation on logout
- Multi-tenancy: every bean/brew is owned by a user (user_id FK, filtered in all queries)
- Security hardened: 22 audit issues resolved (see README Security section)
- Quick Brew logging with style presets, grinder management, agitation timeline, split scoring
- Beans library: search, date filters, edit/copy/delete, usage metadata
- All Cups / Best Cups brew archives
- JSON import/export (rate limited)
- PWA with offline queue (localStorage) that syncs on reconnect
- Metrics dashboard (top beans, recent brews, rating trends)

Environment Variables (backend/.env.example is the source of truth)
- DATABASE_URL          PostgreSQL connection string
- DEBUG                 true in dev; false in prod triggers startup guards
- JWT_SECRET            32+ chars; crashes at startup if missing/weak in prod
- JWT_EXPIRY_HOURS      Default 24
- COOKIE_SECURE         Must be true in production (HTTPS)
- COOKIE_DOMAIN         Your domain in production
- RESEND_API_KEY        Leave blank → links printed to container logs
- MAGIC_LINK_EXPIRY_MINUTES  Default 15
- FRONTEND_URL / API_URL     Used for CORS + magic link URL construction

Runtime / dependency upgrades

- Node 20 -> 24 (Dockerfile + CI)
- Backend: fastapi 0.115->0.141, pydantic 2.9->2.13, sqlalchemy 2.0.34->2.0.52,
  alembic 1.13->1.19, psycopg 3.2->3.3, pyjwt 2.9->2.13, resend 2.5->2.42,
  slowapi 0.1.9->0.1.10, pytest 8->9, httpx 0.27->0.28, ruff 0.6->0.16
- Frontend: react 18->19, react-router-dom 6->7, vite 5->8, tailwindcss 3->4,
  vitest 2->4, typescript 5.6->7, plus testing-library/jsdom/chart.js bumps

Breaking migrations handled
- Tailwind v4 is CSS-first: tailwind.config.js DELETED; theme moved to an @theme
  block in frontend/src/styles/index.css. PostCSS now uses @tailwindcss/postcss;
  autoprefixer removed. All custom utilities verified present in compiled CSS.
- TypeScript 7 dropped Node10 module resolution -> tsconfig uses "Bundler".
- httpx 0.28 deprecated per-request cookies= -> set on client instance in tests.
- ruff 0.16 expanded defaults: DTZ011 ignored (brew dates are local calendar
  days, not timestamps); B008 scoped via extend-immutable-calls for FastAPI
  Depends/Query.

Bugs found and fixed during the upgrade
- BrewUpdate.date could NEVER be updated. Under `from __future__ import
  annotations`, the field name `date` shadowed the imported datetime.date, so
  the annotation resolved to Optional[None] and every real date 422'd.
  Fixed via `import datetime as dt`; regression test test_update_brew_date added.
- QuickLogBar DraftForm used `BrewDraft & {bean_weight_g: number | ''}`, which
  collapses to `number` — the blank-input state added in 06c3deb was invisible to
  the type checker, and switching brew style with a blank weight zeroed the water
  weight. Fixed with Omit<> plus a blank guard in the yield effect.
- seed_db.py used SEED_USER_EMAIL "demo@coffee-journal.local"; EmailStr rejects
  reserved TLDs, so the seeded account could never sign in. Now env-driven
  (SEED_USER_EMAIL) with a valid default. Also fixed a duplicated dict pop that
  mutated module-level SAMPLE_BREWS and made a second seed() call skip all brews.

Test baseline: 71 backend (was 70), 17 frontend. ruff clean.

Known gaps (carried forward + new)

- legacy@coffee-journal.local (migration 20260325_08 backfill placeholder) keeps
